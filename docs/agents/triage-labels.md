# Triage labels

| Git-BBQ role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Work needs maintainer evaluation. |
| `needs-info` | `needs-info` | Waiting for a missing answer or source. |
| `ready-for-agent` | `ready-for-agent` | Acceptance criteria are clear for an agent to implement. |
| `ready-for-human` | `ready-for-human` | Requires a human to implement or decide. |
| `wontfix` | `wontfix` | The project will not action the issue. |
